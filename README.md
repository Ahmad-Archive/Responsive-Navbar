# Ahmad Archive - Navbar

Komponen navbar yang berfungsi sebagai navigasi utama pada website. Yang memudahkan pengguna untuk berpindah antar halaman.

Yang dibangun menggunakan React Vite, dan fontsource.

---

## 📋 Prasyarat

Pastikan perangkat Anda sudah terpasang:

| Tools | Versi Minimum | Cara Cek |
|-------|---------------|----------|
| [Node.js](https://nodejs.org) | v20+ (disarankan LTS) | `node -v` |
| npm | v10+ (bawaan Node.js) | `npm -v` |
| Git | v2.30+ | `git --version` |

---

## Proses Instalasi & Menjalankan Website

### 1. Clone Repository
```bash
git clone <repository-url>
```

### 2. Install Dependencies & Font
```bash
npm install
npm install @fontsource-variable/<font-name>
```

### 3. Jalankan Development Server
```bash
npm run dev
```

### 4. Build untuk Produksi
```bash
npm run build
```

### 5. Jalankan Production Server
```bash
npm run preview
```
